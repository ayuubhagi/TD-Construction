# TD Construction

Website I built for TD Construction, a flooring and stairs company in Kitchener-Waterloo (hardwood, laminate, vinyl plank, tile, and custom staircases).

It's a single static page (HTML, CSS and vanilla JavaScript, no framework) with services, why-us, service areas, an FAQ and a free-quote form.

## What I focused on

- **Local search.** Title and meta description built around flooring and stairs in Kitchener, Waterloo, Cambridge and Guelph, Open Graph tags, and `HomeAndConstructionBusiness` structured data.
- **Getting quotes.** The quote form is linked from the hero and repeated at the end of the page.
- **Mobile first.** Layout is built for phones and scales up to desktop.

## Running it

Open `index.html` in a browser. There's no build step, so any static host (Cloudflare Pages, GitHub Pages, Netlify) can serve the repo root as-is.
